# Contributing to the 11footy dataset

The dataset is rebuilt in full after each round, so it is not edited by pull request. Help comes
through issues.

## Where to write

- **A wrong or missing fact** (a score, a goal, a scorer, a minute, a line-up, a date): the
  "Data correction" form. Give the match, the file and table, what the dataset says, what is
  right, and a public reference anyone can check.
- **A file that does not open, a checksum that does not match, a broken CSV**: the
  "Dataset problem" form.
- **A question about the files or the schema**: the "Question" form, or Discussions.
- **A security problem or personal data in a file**: never in public; see `SECURITY.md`.
- **A request to remove data**: write to `11footy.game@gmail.com`.

A correction we accept is applied in the next release and listed in `CHANGELOG.md`.

## The licence

The dataset is free for non-commercial use under CC BY-NC 4.0 (`LICENSE`), credit "11footy".
By sending a correction you agree that it may be included in the dataset under that licence.

## Ground rules

- Be kind and stay on topic.
- Gambling content and links to gambling services are removed.
